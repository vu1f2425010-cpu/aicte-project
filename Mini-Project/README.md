# Mini Project

## Task Manager Application

- A complete task tracking web app with user login and task filtering.
- Frontend in React, backend in Express, and MongoDB for storage.

## Learning Outcome

Students gain end-to-end experience of connecting frontend and backend with a database.

## Project Files

- `index.html` — basic frontend starter
- `style.css` — styling
- `script.js` — task logic
- `docs/` — project notes
- `assets/` — UI assets

## Login details

This is a demo task manager login screen. There is no real backend authentication yet, so any non-empty username and password will work.

### Example

- Username: `student`
- Password: `123456`

### Password rules for the demo

- Must not be empty
- Minimum length: 4 characters
- Can be any value like `123456`, `student`, or `demo`
