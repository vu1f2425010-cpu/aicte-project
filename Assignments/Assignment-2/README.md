# Assignment 2: User Authentication API

This project implements secure user authentication.

## Features

- User registration
- User login
- Password hashing with bcryptjs
- JWT-based protected routes
- MongoDB persistence

## Run

```bash
cd "c:/Users/shyam/OneDrive/Desktop/aicte/Assignments/Assignment-2"
npm install
npm start
```

## API endpoints

- POST /api/auth/register
- POST /api/auth/login
- GET /api/auth/profile

Use Postman to test the endpoints and send the JWT in the Authorization header.
