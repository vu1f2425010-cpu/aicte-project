# Assignment 1: To-Do List REST API

This project implements a REST API for managing tasks.

## Features

- Create a task
- Read all tasks
- Update a task
- Delete a task
- MongoDB persistence with Mongoose

## Run

```bash
cd "c:/Users/shyam/OneDrive/Desktop/aicte/Assignments/Assignment-1"
npm install
npm start
```

## API endpoints

- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/:id
- DELETE /api/tasks/:id

Use Postman to test the endpoints.
