# AICTE Workspace

This workspace contains the required assignment work and the mini-project for the internship program.

## Structure

- `Assignments/` — assignment folders
- `Mini-Project/` — mini project files

## Assignments

### 1. Full Stack To-Do Application
- Connect Week 2 API with React frontend.
- Implement authentication, CRUD functionality, and routing.

### 2. Image Upload Feature
- Create a file upload endpoint using Multer.
- Integrate with React to preview and display uploaded images.

## Mini Project

### Task Manager Application
- A complete task tracking web app with user login and task filtering.
- Frontend in React, backend in Express, and MongoDB for storage.

### Learning Outcome
Students gain end-to-end experience of connecting frontend and backend with a database.
