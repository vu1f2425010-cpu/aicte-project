## Features

- Product catalog with images, categories, search, and product details
- Add-to-bag flow with quantity controls and item removal
- Checkout confirmation flow
- Admin product form for adding products to the local catalog
- Login validation with the provided credentials
- Responsive neon dark UI with mobile layout
- Product and cart persistence using localStorage
